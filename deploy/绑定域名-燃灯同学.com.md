# 把「燃灯同学.com」绑到你的 App（不用买服务器）

> 原理：电脑上的服务 → Cloudflare 隧道 → 你的域名。全程免费，**不需要买 VPS**。
> 需要你动手的**只有两步**（第 2、3 步），其余脚本我都写好了。

---

## 你要做的（约 5 分钟）

### 第 2 步：注册 Cloudflare 并添加域名
1. 打开 **https://dash.cloudflare.com/sign-up** → 用邮箱注册（免费）
2. 登录后点 **Add a site** → 输入 **燃灯同学.com** → 选 **Free** 套餐
3. Cloudflare 会给你**两个 NS 地址**（形如 `xxx.ns.cloudflare.com`），记下来

### 第 3 步：到 Hostinger 改 NS
1. 登录 **Hostinger** → **Domains** → 点 `燃灯同学.com` → **DNS / Nameservers**
2. 把 nameserver 改成 Cloudflare 给的那两条 → 保存
3. 等生效（10 分钟 ~ 几小时；Cloudflare 面板会显示 Active）

### 然后告诉我「NS 已改」
我在电脑上运行：
```bash
bash deploy/bind-domain.sh
```
它会自动完成：登录 Cloudflare（会弹一个网页让你点授权）→ 建隧道 → 把 `燃灯同学.com` 路由到本机 8080 → 装成开机自启服务。

完成后 → **https://燃灯同学.com 直接打开你的 App**，HTTPS 自动有。

## 注意
1. 电脑要开着（睡眠/关机 = 网站打不开）
2. 想 24 小时在线 → 买 VPS（`deploy/README-部署.md` 那条路）
3. 公网无密码，建议之后给 `/api/chat/` 加限流（nginx 配置里已写好）
