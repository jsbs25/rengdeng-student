## 本轮落地

- 底部产品导航收敛为四项：**首页 / 书库 / NOUR AI / 我的**。
- 搜索移入首页右上角全局能力，不再占用独立底部导航位置。
- 首页新增产品级工作台：
  - 继续阅读：读取既有 `localStorage` 阅读足迹；
  - AI 为你发现：连接现有书库与来源监测能力；
  - 最近阅读、阅读数据、AI 阅读路径入口；
  - 索引式学习工具：生词本、查词与发音、音频与跟读。
- 旧首页 DOM、原有页面、书库、词典、阅读器、AI 和语音函数继续保留；新壳通过适配层调用旧函数，没有重写或删除旧数据结构。
- NOUR AI 由悬浮聊天感改为全屏工作区：保留真实 `homeAIIn`、发送、语音、错误恢复、配额和多语言逻辑；消息区可滚动，输入行位于手机/桌面底部导航上方。
- 产品壳使用深墨色、暖白、哑光金、细线和克制圆角；桌面保留右侧索引，手机收敛为单列。
- 在首页索引中恢复了直接的“查词与发音”入口，避免去 AI 化后语言学习工具变成隐藏功能。

## 远端发布状态

本轮**尚未替换公网文件**，原因是发布前预检发现源站当前不可用：

- `152.239.115.147:22` TCP 可建立，但 SSH 在 `banner exchange` 阶段超时；
- `80/443` TCP 可建立，但 HTTPS 首页、目录接口和主题页均在超时窗口内没有返回；
- 因无法读取远端当前版本，本轮没有创建远端备份、没有上传、没有重启 `nur.service`，避免在无法确认回滚点时进行盲目发布。

恢复发布时应按既有流程执行：

1. 先确认 `nur.service`、`nur-health-monitor.service` 和来源同步 timer 状态；
2. 创建独立回滚目录 `/opt/nur/backups/20261002-nour-product-shell`；
3. 上传产品壳 CSS/JS、生成 HTML 和 `build_home.py` 到临时目录；
4. 语法预检后原子替换，重启主服务；
5. 公网手机/桌面回归，并核验两个 OpenITI 大书、古兰经、词典和 AI；
6. 源站持续不响应时不自动重试，不触碰会员、用户数据或 AI 配置。
