## 已落地

- 新增阿拉伯语闯关中心：关卡地图、词汇选择、语法判断、阿语拼句、即时反馈、生命值、XP、最佳成绩和逐关解锁。
- 阅读器新增 RTL 排版层：阿语方向、阿语字体、可读宽度、行距、词间距和手机安全区。
- 阅读器单词点击改为底部安全卡片：阿语词形、查询状态、解释结果、朗读、收藏和关闭按钮，不再被底部导航遮挡。
- 首页任务卡和快捷指令增加闯关入口。

## 研究得到的产品原则

1. 读中学习：单词解释留在当前阅读上下文中，支持词义、词根、搭配、发音和收藏。
2. 双语渐进：初学者需要短句、重复词汇、逐句译文；高级用户需要原文优先、中文按需展开。
3. 阿语不是简单镜像：RTL 会影响文本流、搜索图标、横向卡片和底部导航；数字、音频进度和代码等内容不应盲目镜像。
4. MSA 与方言分层：后续可在对话中心增加现代标准阿拉伯语、埃及、黎凡特和海湾等场景标签。
5. 反馈要短而可操作：答错后先显示正确答案，再给一条语法原因，并将错题送入间隔复习。
6. 多设备优先：手机使用底部安全区，平板使用更宽的阅读列，笔记本使用更舒适的长文宽度和工具栏布局。

## 下一轮候选升级

- 阅读器增加“原文 / 中阿对照 / 只看译文”三态切换。
- 单词解释加入词根拆解、词形变化和来自当前书籍的上下文例句。
- 闯关增加听音选词、拖拽词块、限时挑战和根据错题自动生成复习关卡。
- 语法课与闯关中心共享完成度，形成“学课 → 闯关 → 复习 → 阅读应用”的闭环。
- 增加 MSA / 埃及 / 黎凡特 / 海湾标签；抓取公开内容时只纳入有明确来源、版权状态清楚或用户已有授权的数据。
