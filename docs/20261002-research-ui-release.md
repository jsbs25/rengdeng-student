## 本轮更新

依据 Quran.com、Al Jazeera Learning Arabic、LingQ、Readlang、Tatoeba 和 Anki 的公开一手页面，提炼了通用交互关系，没有复制第三方品牌、页面、文案、图片、音频、字体或 SVG 路径。

主题页新增：

- **阅读模式**：原文、对照、复习三种状态；用户切换后保留本地偏好。
- **集中朗读控制**：阅读区内直接播放，速度可选慢、标准、快；调用浏览器系统阿拉伯语语音，不强制 AI。
- **今日目标**：10 分钟、1 个单元、自定义三种入口；目标状态写入本地浏览器。
- **来源监测台**：保留上一轮的白名单同步、关键词/类型/状态过滤和许可信息。
- **索引式工作流**：继续以主题索引、正文阅读、按需辅助、学习记录为主，不改成营销式首屏。

## 公开来源同步边界

本轮“同步它们”指同步可解释的交互流程，不指复制第三方内容。服务器仍只通过已有白名单同步任务读取官方元数据和受限样例：

- 不登录第三方站点。
- 不抓取个人、会员或付费内容。
- 不下载整站或整库。
- 单次响应上限 2 MiB。
- 请求间隔 1.1 秒。
- 不覆盖用户、会员、充值和 AI 数据。
