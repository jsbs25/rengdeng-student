# NOUR 阅读器窗口化与 AI 上下文联动发布记录

**时间：** 2026-10-02 14:08–14:12（+03:00）  
**目标：** 将旧的全屏阅读器改为居中的 Apple Books 式阅读窗口，同时保留现有分页、RTL、查词、诵读、页级 AI 与 OpenITI 按需读取。

## 实施内容

- 新增 `data/nour-reader-window.css`：
  - 默认阅读器是带标题栏的居中窗口，外层保留背景舞台和留白。
  - Mac 宽屏使用约 1120px 阅读窗口，中央正文纸页约 790px；手机使用带边距的单列窗口。
  - 正文纸页保持 RTL、阿拉伯字体、纸张色和舒适行距。
  - 原有“全屏 / 退出全屏”仍保留在“更多”菜单，默认不再全屏。
  - `mReader`、分页按钮、目录、朗读、查词和页级分析均沿用原 DOM/函数。

- 新增 `data/nour-reader-context.js`：
  - 读取当前书名、页码、总页数和当前页正文，写入 `window.NOUR_AI_CONTEXT`。
  - 从阅读器进入 NOUR AI 后显示“当前阅读语境已连接”。
  - 对现有 `/api/chat/message` 请求追加书名、页码和正文片段，不替换原 AI 发送函数。
  - 翻页后自动更新语境，关闭阅读器不残留弹层；用户可在 AI 区清除语境。

- `build_home.py` 最末端注入以上资源，避免被旧样式和旧模块覆盖。
- `arabic_learning.html` 与 `v3.html` 已重新生成。

## 发布边界

只替换阅读器视觉层、构建产物和上下文桥接资源；不改用户数据、会员/充值状态、AI 密钥、书库原始数据或 OpenITI 缓存。发布前创建独立远端回滚目录；若视觉效果不符合预期，可只回滚本轮文件。
