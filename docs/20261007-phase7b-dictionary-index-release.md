# 燃灯同学 / NOUR 2.0 阶段 7B：阿拉伯语词典索引发布记录

**阶段：** 7B：本地词典高级查词与词头建议  
**实施日期：** 2026-10-07  
**范围：** 词典查询体验与本地索引；不替换模型、不改用户数据、不下载外部全文。

## 本轮改动

- 新增 `data/dictionary_index.json`：由项目已有 `data/vocab_meanings.json` 与 `data/data.json` 构建。
- 本地开发快照索引覆盖 **295 个固定释义词头、24,325 个真实阿语词元、29,830 句例句**；公网发布没有上传这份本地索引，而是使用生产机已有数据重建：**295 个固定释义词头、19,106 个真实阿语词元、20,164 句例句、39,378 个有界例句位置**。
- 每个词最多保留 6 个例句位置；每个 1—3 字符词头桶最多保留 120 个候选，API 单次最多返回 12 个、前端显示 8 个。
- 新增只读接口：`GET /api/dict/suggest?q=...&limit=...`。
- `/api/dict/lookup` 优先使用索引定位例句，索引缺失或无效时回退到原来的本地扫描逻辑。
- `views.js` 与 `views2.js` 的输入建议改为“本地即时候选 → 服务端真实索引候选”；网络失败仍保留旧本地候选。
- 加入日间/夜间建议面板样式，保留阿语 RTL 与中文 LTR 分区。
- 收紧过宽的相近词匹配：长串无关查询不再因为包含短词而被误报为已找到。

## 缓存修复

公网首次验收发现浏览器命中旧的 immutable `views2.js` 版本号，导致旧建议函数继续运行；随后只更新 HTML 中的 `NOUR_ASSET_VERSION`/资源查询串并原子替换 HTML，未改动业务数据。修复后公网手机/桌面词典专项均为 **10/10**，首页、阅读器、古兰经入口分别为 **11/11、21/21、7/7**。

## 来源与边界

索引只来自项目已有本地数据；没有爬取网站、批量复制受保护全文或把模型生成内容写入词典。词根、词形、释义等需要 AI 的复杂分析仍走既有 NOUR AI/阅读上下文路径；本轮只优化本地查词候选和例句定位。
