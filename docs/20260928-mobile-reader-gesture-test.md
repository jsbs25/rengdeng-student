# 2026-09-28 移动端沉浸式阅读器手势升级

## 变更

- 阅读器正文新增 `touchstart / touchmove / touchend / touchcancel` 监听。
- 横向位移达到 56px 且明显大于纵向位移时翻页：左滑下一页、右滑上一页。
- 纵向手势保留原生惯性滚动，不误触翻页。
- 横向翻页后抑制短暂的合成 click，避免切页后误触沉浸模式或正文操作。
- `touch-action: pan-y`、iOS 惯性滚动、安全区底部留白和 RTL 正文规则已加入阅读器样式。
- 普通阿拉伯原文书（OpenITI）和古兰经共用同一手势层；OpenITI 仍在应用内按页加载，当前页 AI 面板保持挂载。

## 环境说明

当前 Mac WebKit 自动化运行器报告 `navigator.maxTouchPoints=0`，没有连接真实触控硬件，因此自动化测试同时验证了触摸处理函数的降级路径；生产页面已绑定原生 Touch Events，真实 iPhone/iPad 上会走同一监听器。若要测量真实手指触感、系统边缘返回手势和 120Hz 滑动，还需在实体触控设备上手动验收。
