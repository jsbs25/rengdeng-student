# 🚀 燃灯者 · 国外云服务器购买与部署指引

> 用国外服务器：**不需要备案**、随时可用、买家在全国任何地方都能连上。

---

## 一、推荐购买（Vultr —— 支持支付宝，最简单）

| 项目 | 推荐配置 |
|---|---|
| 网站 | https://www.vultr.com |
| 机房 | **东京（Tokyo）或 新加坡（Singapore）** ← 离中国最近，速度最快 |
| 套餐 | **Cloud Compute - Regular**，选 **$6/月（2GB 内存 / 1核 / 55GB）** |
| 系统 | **Ubuntu 22.04 LTS** |
| 付款 | **支付宝**（注册时选 Alipay）|
| 价格 | 约 **¥43/月**（按小时计费，用多少扣多少）|

**购买步骤**：
1. 打开 https://www.vultr.com → 注册（邮箱 + 密码）
2. 注册完点 **Billing** → **Add Funds** → 选 **Alipay（支付宝）** → 充值 ¥60 左右
3. 点 **Deploy** → **Deploy New Server**
4. 选择：
   - Type: **Cloud Compute - Regular**
   - Location: **Tokyo**（或 Singapore）
   - Image: **Ubuntu 22.04 LTS**
   - Plan: **$6/mo**（2GB 内存那档）
   - Server Hostname: `nur-server`
5. 点 **Deploy Now** → 等 1-2 分钟
6. 服务器列表出现后，记下 **IP Address**（形如 `45.76.xx.xx`）和 **root 密码**（点服务器可查看）

> 💡 备选：**Hostinger**（https://www.hostinger.com，$4/月更便宜）、**DigitalOcean**（新加坡机房）
> 但 **Vultr 支持支付宝**，最适合国内用户。

## 二、把部署包传上去

部署包就在你电脑上：`~/Desktop/arabic-learning/nur_cloud/` 文件夹

**Mac 上操作**（打开"终端"Terminal，复制粘贴执行）：

```bash
cd ~/Desktop/arabic-learning
scp -r nur_cloud root@你的服务器IP:/root/
```

> 第一次会问 `yes/no`，输入 `yes` 回车；然后输入服务器 root 密码

---

## 三、登录服务器并一键部署

```bash
ssh root@你的服务器IP
cd /root/nur_cloud
chmod +x deploy.sh
./deploy.sh
```

**部署脚本会自动**：
1. 安装 Python
2. 安装依赖（edge-tts 语音）
3. 检查 AI 密钥（data/ai_key.txt —— 记得把电脑上那个密钥文件复制到 nur_cloud/data/ 里再上传！）
4. 启动服务（端口 8080）

---

## 四、放行防火墙端口（必做！）

**Vultr 控制台操作**：
1. 点你的服务器 → **Settings** → **Firewall**
2. 点 **Add Firewall Group** → 添加规则：
   - **TCP / 8080 / 来源 Anywhere (0.0.0.0/0)**
   - **TCP / 22 / 来源 Anywhere**（SSH，默认已有）
3. 把防火墙组 **Assign** 到服务器

## 五、验证 + 打包新 App

1. 浏览器打开 `http://你的服务器IP:8080` → 看到燃灯者网页 = 成功！
2. 把 **服务器 IP** 发给管理员（我）
3. 我把 App 里的默认地址改成云 IP → 重新打包 → 全国买家都能用了！

## 六、日常维护（很简单）

| 操作 | 方法 |
|---|---|
| 查看服务状态 | `ssh root@IP` → `curl http://127.0.0.1:8080`（返回 200 = 正常）|
| 重启服务 | `cd /root/nur_cloud && pkill -f cloud_server.py && nohup python3 cloud_server.py > server.log 2>&1 &` |
| 查看日志 | `tail -20 /root/nur_cloud/server.log` |
| 管理后台 | 浏览器开 `http://IP:8080/admin`（生成激活码/看用户/改 AI）|
