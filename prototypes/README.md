# 燃灯同学 · 首页设计探索原型 (Homepage Design Exploration)

这是「RENGDENG STUDENT · DESIGN EXCELLENCE DIRECTIVE」第一阶段的可交付成果：**三种明显不同、可运行**的首页设计方向原型。

## 如何查看

三个原型都是自包含静态 HTML（内联 CSS + 少量原生 JS，零外部依赖、零构建、零网络），**直接双击文件即可在浏览器打开**：

- `home-direction-a-immersive.html` — 方案 A：极简沉浸式知识空间
- `home-direction-b-adaptive.html` — 方案 B：自适应动态知识环境
- `home-direction-c-editorial.html` — 方案 C：编辑式知识探索空间

也可以打开 `index.html` 作为三个方案的导航入口。

> 三个文件均内置「深浅色切换」，右上/右下角有「设计原型 · 非功能页面」徽章，且正确处理阿拉伯语 RTL、`env(safe-area-inset-*)` 安全区、`:focus-visible` 焦点环与 `prefers-reduced-motion`。

## 三种方案的真正差异（非仅换色）

| 维度 | 方案 A | 方案 B | 方案 C |
| :--- | :--- | :--- | :--- |
| **信息架构** | 线性「知识路径」，内容沿单轴依次展开 | 任务驱动的多模式工作区（阅读/研习/探究） | 编辑式「卷」与栏目，杂志化层级 |
| **空间布局** | 极窄阅读版心 + 大面积留白 | 情境侧栏 + 中央画布 + 知识图谱 | 非对称编辑网格 + 主推长文 + 紧凑条目 |
| **导航方式** | 无固定顶/底导航，角落目录 + 专注模式 | 顶栏「模式切换器」= 情境化导航 | 安静持久顶栏 + 锚点卷章 |
| **交互逻辑** | 滚动叙述 + 节点展开 + 专注压暗 | 模式切换让界面变形 + 多任务置顶 | 相关发现链条（词→句→书→史→人物） |

## 五轮评审（概要）

1. **视觉**：三方案均严格使用 `#FFFFFF / #F5F5F7 / #1D1D1F / #86868B / #D2D2D7` + 品牌橄榄绿 `#1B4D3E` / 哑光金 `#B08D40`，拒绝霓虹、发光边框、3D 球体、大量渐变与过度玻璃拟态。
2. **交互**：每条路径都尽量少步骤；A 的角落目录、B 的模式切换、C 的相关发现均直接服务真实任务。
3. **产品**：A 解决「阅读沉浸」，B 解决「多任务与知识关系」，C 解决「知识发现与浏览」。
4. **技术**：纯 HTML/CSS/JS，性能极轻，无外部依赖，可访问性好。
5. **整体**：三个方案共享同一套品牌令牌与 RTL/排版纪律，气质统一但布局各异。

## 结论：选择「方案 B：自适应动态知识环境」作为深化方向

理由：

- 它最贴合「下一代知识产品」的愿景——界面随任务自适应、知识关系可视化、多任务工作空间、情境化导航，是三种方案里**创新程度、信息组织与长期扩展能力**最强的一个。
- 但它不与另两个方案对立，而是它们的**组织骨架**：
  - 在「阅读」模式下，退化为 **方案 A** 的沉浸式阅读体验（内容成为视觉中心、界面退后）；
  - 在「发现 / 首页」语境下，借用 **方案 C** 的编辑式层级与相关发现链条，降低首次进入的认知负担。

因此，下一步将围绕方案 B 深化，把 A 的沉浸与 C 的编辑组织内化为它的两个模式，形成统一而完整的设计哲学，并在此后逐页推广。
